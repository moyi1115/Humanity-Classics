# 神曲：导读

## 关于本书

《神曲》(Divine Comedy) 是意大利诗人但丁·阿利吉耶里 (Dante Alighieri) 于1308年至1320年间创作的长诗，分为三部分：地狱篇、炼狱篇、天堂篇。

这是一部关于灵魂之旅的史诗。但丁在诗中描述了自己在人生中途迷路，被古罗马诗人维吉尔引导，穿越地狱、炼狱，最终到达天堂，见到了他一生挚爱贝阿特丽切和神。

这不仅是一部文学杰作，更是一部关于人类心灵、道德、罪与救赎的深刻探索。

## 核心主题

1. **罪与惩罚**：地狱中的灵魂不是被神惩罚，而是被自己的选择困住
2. **净化与成长**：炼狱是灵魂净化的过程，痛苦是成长的必要
3. **爱与秩序**：天堂是爱的圆满，万物各得其所
4. **迷途与回归**：每个人都在人生中途迷路，但总有路可回

## 品读框架

本品读采用"旅程精读"框架：

1. **原文精摘** — 关键段落
2. **旅程之思** — 3个小节深度解读
3. **古今对话** — 与其他经典的对话
4. **心灵实践** — 当代应用

## 阅读建议

- 不要把地狱、炼狱、天堂当作"地理"来读，而是当作"心灵状态"来读
- 每一个场景都在描述你内心的某个部分
- 注意但丁的旅程：从迷路到觉醒，从恐惧到爱
