# 大鱼导师 (kun-wisdom)

一个不会灌鸡汤的 AI 心灵陪伴助手。

## 一句话描述

你焦虑的那些问题——工作到底为了什么、怎么和重要的人相处、我是不是不够好——释迦牟尼想过，庄子想过，奥勒留也想过。大鱼导师从 29 部人类经典里找到和你的处境对应的地方，跨着文明帮你看见自己。

## 为什么叫"大鱼"

大鱼 = 大愚。大智若愚，真正的智慧看起来往往有点笨。

庄子的《逍遥游》开篇："北冥有鱼，其名为鲲。鲲之大，不知其几千里也。化而为鸟，其名为鹏。"

那条沉在深海的大鱼，平时看不见，但你要渡海的时候，它会浮上来载你一程。这个 Skill 的想法就是这样——平时不打扰你，你想起它的时候，它就在这里。

## 和别的 AI 助手有什么不一样

**它记得你。**
你说过的话，你的困境和变化，它都记着。下次再聊的时候，它不用从头认识你。大部分 AI 助手都是"一次性对话"，每次打开都是陌生人。大鱼导师不是。

**它不灌鸡汤。**
"加油""一切都会好起来的""你值得被爱"——这类话它不会说。它会告诉你，承认困难比假装正能量更需要勇气。奥勒留也好，庄子也好，都不是天天开心的人。

**它让你自己去琢磨。**
不给标准答案，不替你决定。它把经典里的想法摆在你面前，你自己看。它相信你能想明白。

## 使用场景

你可以在这些时候找它聊聊：

- 工作压力大，脑子停不下来
- 不知道自己做的事情有什么意义
- 和重要的人之间出了问题，不知道该怎么做
- 反复陷入同一种困境，不知道问题出在哪
- 想读点经典但不知道从哪里开始
- 就是想找个不会敷衍你的人说说话

## 怎么用

### 触发方式

当你聊到和上面那些场景相关的话题时，大鱼导师会自动介入。它不会主动跳出来打扰你——只有在你需要的时候才出现。

你也可以直接说"找大鱼导师聊聊"来手动唤起它。

### 第一次对话

它会先听你说，不会急着丢一堆经典出来。它想搞清楚三件事：你现在卡在哪里、这个问题背后的核心是什么、和哪些经典可能有关联。然后它会选 1-2 部最相关的经典，从一个小切口进去——不会一次讲太多。

### 后续对话

第二次聊的时候，它会先加载上次的记忆。它可能会说"上次你提到..."——这说明它记得你。这种连续性是它最重要的特点。

### 记忆管理

每次对话结束，你的画像和对话记录会自动更新。你的隐私数据不会被公开——这些文件只在你本地。

每 20 次对话后，系统会自动清理一次：保留最近 5 次的详细记录，更早的对话只保留关键洞察。这样既不会丢东西，也不会越堆越多。

## 技术实现

### 架构

```
kun-wisdom/
├── SKILL.md              # 系统提示词（角色定义、检索策略、对话流程、记忆逻辑）
├── index.md              # 主题索引（10 个主题 × 关键词映射 × 快速检索表）
├── memory/
│   ├── wisdom-profile.md # 用户画像（价值观、困境、偏好、成长轨迹）
│   └── wisdom-history.md # 对话历史（每次对话的关键信息、模式识别）
├── examples/
│   ├── example-1-first-session.md
│   └── example-2-returning-user.md
├── README.md             # 本文件
└── [29 个品读目录]       # 知识库（487 个 markdown 文件）
```

### 检索策略

```
用户问题 → 提取关键词 → 匹配主题 → 读取相关经典品读 → 跨经典连接 → 综合回应
```

index.md 维护了 10 个主题分类和 13 组关键词映射表,确保每次检索都精准快捷。

### 记忆系统

这是大鱼导师和普通 AI 助手最大的区别。它有两个层级：

1. **用户画像**: 记录你的核心价值观、常见困境、对话偏好、成长轨迹。这部分变化很慢。
2. **对话历史**: 记录每次对话的关键信息、你的反馈、你的变化。每 20 次对话自动精简。

对话过程中每 3-5 轮就更新一次记忆——不等到对话结束,防止你中途关掉窗口导致记录丢失。

## 已知限制

- 不替代心理咨询。遇到严重的心理健康问题,请寻求专业帮助。
- 经典是几千年前的智慧,不是所有现代问题都能对上号。对不上的时候它会直说。
- 记忆系统依赖本地文件存储。如果你换了设备,记忆不会自动同步。
- 第一次使用的时候它是空白的,需要几次对话才能建立起对你的理解。
