# 人类经典品读

> 跨文明经典著作深度品读系列，融合禅宗公案、历史典故与现代生活实践

## 项目简介

这是一个**人类经典品读系列**内容项目，目标是对跨文明的经典著作进行深度品读，结合禅宗公案、历史典故与现代生活实践，探索人类智慧的共通之处。

**覆盖文明：** 佛家、道家、儒家、西方哲学、基督教、伊斯兰教、印度教

## 品读框架

每篇品读包含四个核心板块：

### 佛家经典

1. **经文原文** — 原典原文
2. **走进般若** — 3个小节深度解读
3. **公案点睛** — 禅宗公案与义理呼应
4. **生活化品读** — 现代生活实践

### 道家经典

1. **原文** — 原典原文
2. **道之理** — 3个小节深度解读
3. **历史镜鉴** — 历史典故呼应
4. **生活智慧** — 当代应用

### 儒家经典

1. **原文** — 原典原文
2. **圣贤之言** — 3个小节深度解读
3. **古今对话** — 历史人物对照
4. **修身践行** — 具体实践方法

### 西方哲学

1. **原文摘录** — 关键段落
2. **哲人之思** — 3个小节深度解读
3. **时代回响** — 历史背景与当代意义
4. **现实映照** — 现代生活应用

### 宗教/智慧文学

1. **原文摘录** — 关键段落
2. **智慧之言** — 3个小节深度解读
3. **古今对话** — 历史背景与多元解读
4. **当代启示** — 现代人实践方法

## 写作特点

- **思想深度 > 文字数量**：每章1500-2000字，宁精勿滥
- **直指核心**：每个观点一针见血，不做百科式解释
- **跨文明对话**：不同经典、不同文明之间的思想碰撞
- **实践导向**：触及现代人真正的痛点（焦虑、身份执着、控制欲等）
