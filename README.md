> 跨文明经典著作深度品读系列，融合禅宗公案、历史典故与现代生活实践

[English Version](README_EN.md)，并且蒸馏成了导师skill （大鱼导师） ，有长期记忆能力。

## 项目简介

这是一个**人类经典品读系列**内容项目，目标是对跨文明的经典著作进行深度品读，结合禅宗公案、历史典故与现代生活实践，探索人类智慧的共通之处。

**覆盖文明：** 佛家、道家、儒家、西方哲学、基督教、伊斯兰教、印度教

## 品读框架

每篇品读包含四个核心板块：

### 佛家经典

1. **经文原文** — 原典原文
2. **走进般若** — 3个小节深度解读
3. **公案点睛** — 禅宗公案与义理呼应
4. **生活化品读** — 现代生活实践

### 道家经典

1. **原文** — 原典原文
2. **道之理** — 3个小节深度解读
3. **历史镜鉴** — 历史典故呼应
4. **生活智慧** — 当代应用

### 儒家经典

1. **原文** — 原典原文
2. **圣贤之言** — 3个小节深度解读
3. **古今对话** — 历史人物对照
4. **修身践行** — 具体实践方法

### 西方哲学

1. **原文摘录** — 关键段落
2. **哲人之思** — 3个小节深度解读
3. **时代回响** — 历史背景与当代意义
4. **现实映照** — 现代生活应用

### 宗教/智慧文学

1. **原文摘录** — 关键段落
2. **智慧之言** — 3个小节深度解读
3. **古今对话** — 历史背景与多元解读
4. **当代启示** — 现代人实践方法

## 写作特点

- **思想深度 > 文字数量**：每章1500-2000字，宁精勿滥
- **直指核心**：每个观点一针见血，不做百科式解释
- **跨文明对话**：不同经典、不同文明之间的思想碰撞
- **实践导向**：触及现代人真正的痛点（焦虑、身份执着、控制欲等）

## 大鱼导师

本项目包含一个 **大鱼导师 (Wisdom)** skill，基于经典品读资料提供深层对话。

### 什么是大鱼导师？

大鱼导师是基于31部经典品读资料的智识导师，帮助用户在现实困境中获得经典智慧的启示。

**名字由来：** 取自电影《大鱼海棠》，也代表"大智若愚，大愚音译为大鱼"。

### 如何使用？

在 Claude Code 中输入：

```
/wisdom
```

### 核心功能

- **不止是检索，更是领悟**：理解你的困境，在多部经典之间建立深刻的内在联系
- **不止是答案，更是启示**：帮助你从经典思想中获得自己的感悟与力量
- **不止是解决，更是成长**：每次对话都是一次内在的修行

### 记忆系统

大鱼导师具有记忆功能，能记住你的对话历史和成长轨迹：

- **用户画像**：记录你的核心价值观、常见困境、对话偏好
- **对话历史**：记录每次对话的关键信息
- **自动清理**：每20次对话自动清理，保持对话效果

### 使用场景

当遇到以下问题时，可以与大鱼导师对话：

- 工作焦虑、身份迷茫
- 人际关系困惑
- 意义追寻
- 修行实践中的困惑
- 需要经典智慧的启示

### 示例对话

**用户：** 我最近工作压力很大，总是焦虑。

**大鱼导师：** 我记得我们之前讨论过身份焦虑的问题...之前我们在金刚经中找到了"应无所住"的智慧，但这次你提到的是工作压力。这让我想到道德经说的"宠辱若惊"——我们太在意结果，反而失去了过程中的平静...

### 注意事项

- 提供的是经典智慧的启示，不是专业建议
- 引导用户自我探索，不是替用户做决定
