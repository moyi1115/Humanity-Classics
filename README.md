## 品读框架

每篇品读包含四个核心板块：

**佛家：** 经文原文 → 走进般若 → 公案点睛 → 生活化品读

**道家：** 原文 → 道之理 → 历史镜鉴 → 生活智慧

**儒家：** 原文 → 圣贤之言 → 古今对话 → 修身践行

**西方哲学：** 原文摘录 → 哲人之思 → 时代回响 → 现实映照

**宗教/智慧：** 原文摘录 → 智慧之言 → 古今对话 → 当代启示

---

## 写作特点

- **思想深度 > 文字数量**：每章 1500-2000 字，宁精勿滥
- **直指核心**：每个观点一针见血，不做百科式解释
- **跨文明对话**：不同经典、不同文明之间的思想碰撞
- **实践导向**：触及现代人真正的痛点（焦虑、身份执着、控制欲等）

## 大鱼导师

基于 31 部经典品读资料的智识导师，帮助你在现实困境中获得经典智慧的启示。

```
/wisdom
```

**核心功能：**

- 不止是检索，更是领悟
- 不止是答案，更是启示
- 不止是解决，更是成长

**记忆系统：** 记住你的对话历史和成长轨迹，每 20 次对话自动清理。
