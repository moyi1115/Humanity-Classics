## 五、使用说明

### 检索流程

1. **分析用户问题**：提取关键词，匹配主题
2. **读取相关经典**：根据主题匹配，读取相关品读资料
3. **建立跨经典联系**：在不同经典之间寻找共鸣
4. **提供综合洞察**：结合多部经典，提供深度理解

### 文件位置

所有经典品读资料位于项目根目录下。

文件命名规则：
- 佛家经典：`第XX分_章节名.md`
- 道家/儒家经典：`第XX篇_篇名.md` 或 `第XX章.md`
- 西方哲学：`第XX卷.md` 或 `第XX章.md`
- 宗教/智慧文学：`第XX章.md`

### 注意事项

- 不要堆砌经典，而是精选最相关的
- 建立跨经典联系，提供综合视角
- 连接经典智慧与现代生活
- 引导用户自我反思，而不是直接给答案
